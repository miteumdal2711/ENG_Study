연습 기록

Claude API 키

이 버전은 Claude Haiku 5.5로 앱 안에서 바로 피드백을 받아요. 키를 넣으면 AI 새 문제도 만들 수 있어요.

  1. console.anthropic.com에 로그인해 Create Key로 키를 만듭니다.
  2. Billing에서 크레딧을 충전하고, 월 사용 한도(Limits)를 낮게 정해 두세요.
  3. 키는 이 휴대폰 브라우저에만 저장되고 Anthropic 서버로만 보내집니다.

Claude Haiku 5.5를 써서 피드백 1회에 대략 1~3원 정도 들어요. Claude 구독과는 별도로 결제돼요.

매일 알람

요일
Google 캘린더에 매일 알람 등록
  1. 위 버튼을 누르면 반복 일정이 채워진 Google 캘린더가 열립니다. 저장을 누르세요.
  2. 일정의 알림을 "일정 시작 시"로 바꾸면 정해진 시간에 휴대폰 알림이 옵니다.
  3. 알림의 링크를 누르면 이 앱이 열립니다.

웹앱은 닫혀 있을 때 스스로 소리를 낼 수 없어서 캘린더 알림을 알람으로 씁니다. 앱이 열려 있을 때는 알람 시간에 소리로도 알려 드려요.

난이도

피드백 기준과 AI가 만드는 새 문제의 난이도에 적용됩니다. 기본 문제은행은 800점 수준(CEFR B2)입니다.
